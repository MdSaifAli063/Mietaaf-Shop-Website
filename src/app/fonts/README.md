# Bundled brand fonts

The Latin variable WOFF2 files are DM Sans and Cormorant Garamond from Google Fonts, retained from the project's existing font assets. They are loaded with `next/font/local` so development and production builds do not need to download fonts or resolve Google Fonts through Turbopack.

Both fonts use the SIL Open Font License. The corresponding copyright notices and full licenses are included alongside the font files.
